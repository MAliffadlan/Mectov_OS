## Restyle icon desktop (v38.46) — murni visual, geometri tidak berubah

**Temuan kunci dari eksplorasi:**
- Icon digambar di `draw_pro_icon()` (`src/gui/desktop.c:109`): tile rounded 44×44 flat + glyph sederhana; label teks putih polos + bayangan 1px di bawah tile.
- Lapisan vga **sudah punya** semua primitif yang dibutuhkan: `draw_soft_shadow()` (bayangan feathered), `draw_gradient_v()`, `draw_rounded_rect_border()`, `draw_rect_alpha()`.
- **Aman untuk CI:** semua harness men-double-click icon Terminal di posisi tetap (60,64) dan hanya memverifikasi *bentuk kursor* dari screendump — tidak ada test yang meng-audit pixel icon. Selama posisi grid (`start_x=24, start_y=24`, cell 72×80, hit-box) tidak berubah, tampilan bebas diubah.
- Tidak ada state hover/selection pada icon desktop (hanya menu klik-kanan yang punya hover) — tidak ada yang perlu disinkronkan.

## Perubahan (semua di `src/gui/desktop.c`)

1. **Bayangan lembut** di bawah tiap tile: `draw_soft_shadow(x, y, 44, 44, 12, 96)` — tile terangkat dari wallpaper.
2. **Tile gradient vertikal rounded** (helper baru ±20 baris, `rounded_gradient_rect`): tiap baris lerp warna atas→bawah, sudut rounded pakai tabel inset precomputed untuk r=12 (tanpa sqrt per frame). Radius dinaikkan 10→12 agar lebih squircle.
3. **Depth cue solid-color** (tanpa blending per-pixel): rim 1px lebih terang via `draw_rounded_rect_border` + band gloss 3px di bawah tepi atas.
4. **Palet 2-tone per app** yang lebih kaya menggantikan flat color: Terminal slate gelap, Explorer biru, Browser emas, Snake hijau, Calc ungu-indigo, ELF magenta, dsb. (12 app + default).
5. **Perbaikan glyph**: Terminal `>_` neon hijau terang; **Notepad** diganti glyph halaman putih + garis biru (sekarang glyph putih di atas tile abu terang — kontrasnya buruk); mata Snake disesuaikan dengan warna dasar baru.
6. **Label chip**: teks label kini di atas chip rounded gelap solid (±18px, radius 6) menggantikan teks putih polos — jauh lebih terbaca di atas wallpaper. Logika clip label yang ada tetap dipertahankan.
